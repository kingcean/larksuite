# LarkSuite Oapi

This is the core library of LarkSuite SDK for Open API.

## Common-used types

- `LarkApi`: This is the entry point to access the resources of LarkSuite.
- `LarkApiUtils`: Additional utitilies for `LarkApi` and its response models.

## CLI

This project can build the command line application for accessing LarkSuite resources.

You can configure the environment to initialize the default AK/SK.

## Environtment

- `LARK_OAPI_APP_ID`: The default app ID used.
- `LARK_OAPI_APP_SECRET`: The app secret key.
- `LARK_ME_OPENID`: The open ID of current user (me).
